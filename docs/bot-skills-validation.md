首次完整测试暴露了新增文案未覆盖其他语言的问题，已通过共享英文回退补齐，并保持原有 i18n 检查不变。一个原有 PTY 时序用例首次未在时限内完成，单独复测与随后完整服务端测试均通过，未修改其测试阈值。

浏览器验收完成了本地 Skill 导入、绑定、上下文预览和 Bot 创建。创建时补充指令留空，自动问候通过本地 ACP fixture 接收到 Skill 上下文；随后保存补充指令，并通过服务端状态确认指令和绑定已持久化。预览包含完整入口正文和快照路径，未包含未选择的参考文件正文。

跨窗口场景通过向隔离服务提交另一份配置模拟：编辑表单显示冲突提示并保留草稿，重新载入后展示远端指令。版本恢复场景先导入新版本，再故意损坏隔离环境中的旧测试快照；界面显示 `SKILL_CORRUPT`，仍允许选择、应用和保存有效的新版本，旧错误随绑定更新消失。

独立 Code Review 发现并修复了同时重复导入的幂等性问题、GitHub 子目录配置缺失，以及旧版本损坏时无法应用新版本的问题。并发导入增加了回归测试，其他恢复流程经浏览器验证。

真实 GitHub 验收使用用户提供的马斯克与乔布斯仓库，完整文件快照和正文编译均成功。马斯克包包含 11 个文件，乔布斯包包含 14 个文件；两包共 11 份参考文本分别显式附加成功。二进制文件不能作为文本附加，超过上下文预算的组合明确报错。乔布斯首次下载流中断，重试成功，说明远程导入仍受网络状态和 GitHub API 额度影响。

本次模型链路验证使用模拟 provider、真实 ACP SDK 传输 fixture 和模拟 FastClaw HTTP 服务，验证实际请求载荷、流式返回、配置替换及会话复用。未调用付费模型，也未把人物风格主观效果作为自动化通过条件。没有执行 macOS 应用安装包签名或发布。

使用入口：创建 Bot 或打开 Bot 设置，填写简介，导入并绑定 Skill，按需填写补充指令，预览后保存。快照保存在 `~/.termany/skills/<skill-id>/<revision>/`，参考文件默认由具备文件工具的本地 Agent 按需读取。
