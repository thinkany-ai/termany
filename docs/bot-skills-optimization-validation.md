# Bot Skill 优化验收记录

日期：2026-09-27。对应桌面版本：`0.2.6-bots.3`（Apple Silicon）。

## 实现结果

- 搜索覆盖 Agents、Claude、有效 Codex Home 和 Termany 下载目录；设置中可添加、停用、移除搜索根。
- 本地目录直接引用；realpath 去重、完整包内容去重；同名但资源不同的包保留。去重只合并展示，不改写已有绑定来源。
- 删除版本管理和补充指令 UI。“描述”承担角色及回答要求，旧指令完整合并；旧精确快照绑定保留兼容定位。
- 独立多选面板、GitHub 导入自动选中、全局目录管理；标题、搜索与底部操作固定，内容区滚动。
- GitHub 使用一次 codeload 归档下载；入口选择复用缓存。错误区分403权限/限流、404、429、网络中断、非法归档等。
- 默认只发送描述、绑定 Skill 元信息和绝对 `SKILL.md` 路径。Agent 使用自身文件工具读取入口及按需参考文件。
- ACP 按运行实例同步：首次/变更/恢复发送快照，普通轮次短提醒。失败/取消不提交成功状态。命令保持原样，明确的重置类命令之后保守刷新。

## 存储、迁移与回退

配置索引与搜索根保存于SQLite元数据 `skillCatalog.v2`。本地Skill直接使用原路径；下载包位于 `~/.termany/skills/.managed/`。托管包内部使用不可变发布目录并原子切换当前指针，以免运行中读取半写入文件；这是实现细节，不提供历史版本产品功能。旧目录暂保留，不自动删除用户文件。

启动迁移前使用SQLite `VACUUM INTO` 一致性备份，文件位于 `~/.termany/backups/before-bot-skills-v2-*.db`，覆盖已提交WAL数据。迁移在写事务内重新检查标记和最新会话，避免备份等待期间丢失并发编辑。旧超长描述不会被迁移截断；实际发送超限会明确报错。

回退应先退出应用及后台，另存升级后的数据库，再将迁移前备份恢复为原数据库文件，同时处理同名WAL/SHM，最后启动匹配的旧版本。回退会失去升级后新增的配置；不要让旧进程与新进程同时写同一数据库。

运行配置清单位于 `~/.termany/runtime-profiles/`，单实例文件模式0600；正常关闭删除。异常退出可能留下不含凭据的旧清单。重启或配置变化后，Agent 可按清单中的绝对入口路径重新读取。

首次目录样本：81个展示项、25个重复来源；冷扫描约607ms，缓存读取约0.09ms，进程RSS约102MiB。仅为本机一次样本，不是跨设备性能承诺。扫描深度12、每根最多20000目录，扫描时限按启用根分配；全包去重另有边界，超限保留不同条目而不误合并。
