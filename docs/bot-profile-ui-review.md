# Bot 创建与行为配置界面优化

本次依据实际桌面截图和本地页面验证，覆盖创建 Bot、编辑行为、Skill 选择与头像上传。

| 优先级 | 原问题 | 落地改动 |
| --- | --- | --- |
| P0 | 旧后台缺少 Skill 接口，空 404 被直接解析为 JSON，WebKit 显示 SyntaxError | 区分非 JSON、旧接口和结构化业务错误；显示后台升级说明与刷新入口；保留业务错误码 |
| P1 | 创建表单混入完整 Skill 管理界面，技术说明比任务本身更突出 | 默认展示已绑定 Skill，点击“添加 Skill”后展开库与导入；上下文说明与预览放入折叠区 |
| P1 | 原生控件与现有表单视觉不一致，字段层级和边距混乱 | 沿用现有主题变量、统一 8/12/16/20px 间距、圆角、输入背景、聚焦轮廓与按钮状态 |
| P1 | 绑定后版本、来源和参考文件占据大量空间 | 摘要卡片默认只显示名称、两行描述及排序/移除；版本与参考文件按需展开 |
| P1 | 创建时没有头像入口，不同人物容易混淆 | 名称旁复用已有头像编辑器，预览、恢复默认、上传中禁止提交，关闭表单后丢弃异步上传结果 |
| P1 | 列表无加载状态，搜索无结果缺乏反馈 | 加载中和空列表反馈，错误与恢复入口就地显示 |

设计参考 ui-ux-critic 中 Linear/Vercel 设置表单的分组、label/helper/error 层级及渐进披露原则，不依赖其当前具体像素。ui-ux-pro-max 的表单标签、提交反馈建议用于复核；颜色和字体沿用本项目现有主题，不新增品牌色或动效体系。

## 头像存储

复用 AgentAvatarEditor：支持 PNG/JPEG/WebP/GIF，输入最大 10 MB，居中裁切并缩放成 256×256 PNG。GIF 保存静态帧。PNG data URL 写入 agentAvatar，随 Bot 一次性创建并经现有状态同步持久化到 ~/.termany/termany.db；不保存原文件，不依赖上传服务器。现有 Bot 设置、列表和群聊头像均复用该字段。

对于个人智囊团规模，这种方案无需数据库迁移，复杂度低。若未来存在大量高清图片、跨设备独立同步或头像缓存需求，再考虑文件目录 + 数据库相对路径；当前没有必要扩展后端图片服务。

## 后台兼容说明

本机旧后台 /api/version 返回 0.2.6，/api/skills 返回空 404，已复现错误来源。原生程序检测版本不一致时，会保留仍在运行任务的旧后台，避免打断任务。新包使用 0.2.6-bots.2 与对应服务端版本；结束任务并完全退出后重新打开，新后台才能接管。没有自动杀死用户任务。
